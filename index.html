Inspección de moldes por visión: validar el armado, no la pieza

Trabajo desarrollado para resolver una problemática recurrente de armado de molde durante los cambios de configuración. Los sistemas de visión industrial de catálogo están hechos para inspeccionar la pieza producida; aquí se aplican un paso antes, sobre el herramental, para verificar que el molde quedó armado con los componentes correctos, que es donde se originan colisiones, componentes rotos y scrap.

Problemática que lo originó

Durante el cambio de configuración, distinguir entre componentes de molde con geometría casi idéntica depende del criterio del técnico y del turno. Un armado incorrecto que no se detecta termina en colisión al arrancar producción, con componentes a reemplazar o fabricar y tiempo comprometido con el cliente. Cuando no colisiona, genera scrap y queja de cliente.

Enfoque actual: fotometría estereoscópica

Algoritmo desarrollado en conjunto con el área de AMT, inspirado en fotometría estereoscópica, en la línea de LumiTrax. Se capturan varias imágenes del mismo molde bajo distintas condiciones de iluminación, se calculan las normales de superficie y se estima la topografía. Con eso se detectan errores de ensamble y anomalías sin depender de una red neuronal, lo que hace el resultado interpretable y ajustable en piso.

Alternativas evaluadas

Redes neuronales con extracción de características y data augmentation para generalizar entre familias de molde, y template matching clásico para comparación de patrones. El proyecto combina el enfoque avanzado y el convencional según el tipo de componente a verificar.

Hardware

Robot con cámara y escáner 3D integrado para inspección automática del molde ensamblado, con notificación inmediata al usuario.
